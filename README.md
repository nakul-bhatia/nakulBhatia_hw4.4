# Project Title
HW 4.3 GitHub Repository

This repository contains all materials for HW 4.3 while demonstrating proper use of GitHub version control tools such as branching, commits, issues, and pull requests.

## Overview

The purpose of this repository is to showcase both the results of HW 4.3 and the workflow used to manage and organize the project using GitHub. This includes maintaining a structured repository, tracking progress through issues, and using branches and pull requests to manage updates. The project highlights how version control can support reproducibility, organization, and collaboration in data analysis work.

## Data Sources and Acknowledgements

The data set used in this project is the built-in `mtcars` dataset available in R. This dataset contains information about various car models and their performance characteristics.

Acknowledgement is given to course materials and instructional guidance provided in class, as well as the use of R and the `ggplot2` package for data analysis and visualization.

## Current Plan

The plan for this project includes organizing all required files within the repository, maintaining proper version control practices, and documenting the workflow clearly. This involves:

- Creating and managing branches (main and development)
- Using commits to track progress
- Creating and resolving issues
- Submitting changes through pull requests
- Including all HW #4.3 deliverables (PDF and QMD)

Further details can be found within the project documentation and commit history.

## Repo Structure

The repository is organized as follows:

- `/README.md` – Overview and documentation of the project  
- `/hw4.3Document.pdf` – Final submitted assignment  
- `/hw4.3Document.qmd` – Quarto file used to generate the analysis  
- Other commits and branches demonstrate version control workflow  

This structure is designed to make it easy for users to locate project files and understand the workflow used.
